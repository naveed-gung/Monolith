# Contributing to Monolith

Thanks for your interest! Monolith is source-available (see [LICENSE](LICENSE)) —
personal use is free; commercial use needs a signed agreement.

## Getting started
1. `flutter pub get`
2. `flutter run`

## Before opening a PR
- `flutter analyze` must be clean.
- `flutter test` should pass.
- Keep changes focused and described in the PR body.

## Commit style
Conventional-ish prefixes (`feat:`, `fix:`, `docs:`, `chore:`, `perf:`).

## Reporting bugs
Use the issue templates under **Issues → New issue**.
