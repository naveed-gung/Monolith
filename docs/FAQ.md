# Frequently Asked Questions

### Is Monolith free?
Personal use is free. Commercial use requires a signed license — see [LICENSE](../LICENSE).

### Where are my downloads stored?
In the app's own folder: `Monolith/Music` (and `Monolith/Music/Imports`). On iOS
this shows in Files under **On My iPhone › Monolith**.

### The lock-screen / notification controls don't show.
Make sure a track with a valid local file is playing. On iOS the equivalent
surfaces are the Lock Screen and Control Center (there's no notification-shade card).

### How do I install on iPhone?
Sideload the IPA (AltStore / Sideloadly) or, on a jailbroken / TrollStore-capable
device, install it permanently with TrollStore. See the README's Download section.
